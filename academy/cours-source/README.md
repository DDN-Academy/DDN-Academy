# cours-source/ — dépôt des supports bruts

Tout ce qui vient de la faculté atterrit ici, tel quel. Aucun tri préalable n'est demandé :
le tri fait partie du travail de reconstruction.

## Formats acceptés

| Format | Remarque |
|---|---|
| PDF (polycopié, diapositives) | Le meilleur support. Le texte sélectionnable est préférable au scan. |
| Diapositives (`.pptx`, `.odp`) | Traitées directement. |
| Photos de tableau ou de notes (`.jpg`, `.png`, `.heic`) | Cadrer droit, à la lumière, sans reflet ; une photo par tableau plutôt qu'une vue d'ensemble illisible. |
| Notes manuscrites scannées | Utiles même incomplètes : elles révèlent ce que l'enseignant a insisté à l'oral. |
| Retranscriptions d'enregistrement (`.txt`, `.md`) | Précieuses : c'est exactement la parole absente des diapositives. |
| Sujets d'annales, corrigés, TD | À déposer aussi — ils déterminent le format des sections « entraînement ». |

## Nommage

```
<matiere>-<numero>-<sujet>.<ext>
micro-03-elasticites.pdf
macro-01-comptabilite-nationale-slides.pdf
maths-02-td-derivees.pdf
```

## Ce qu'il est utile de préciser en déposant un cours

Chacune de ces informations change le document produit ; aucune n'est obligatoire.

- **L'échéance** : partiel dans trois semaines ou contrôle demain ne se préparent pas pareil.
- **Le format de l'épreuve** : durée, QCM, exercices, dissertation, documents autorisés,
  calculatrice. Sans cette information, la section « simulation d'examen » est construite
  sur le format le plus probable, et le dit explicitement.
- **Le coefficient** de la matière.
- **Les passages incompris** en cours : ils reçoivent un traitement renforcé.
- **Ce que l'enseignant a insisté** à l'oral, même approximativement.
- **Le support est-il complet ?** Diapositives partielles, séance manquée, tableau non
  recopié : le dire permet de reconstruire le chaînon manquant au lieu de l'ignorer.

## Sources illisibles

Une photo floue, une formule tronquée, un mot indéchiffrable ne sont jamais devinés :
ils sont signalés explicitement dans le document produit, à l'endroit exact, avec la
demande de la donnée manquante. Un chiffre inventé vaut moins qu'un trou signalé.
